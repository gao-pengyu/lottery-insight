# 彩票信息网站产品需求文档 PRD

## 1. 产品概述

### 1.1 产品名称

暂定名称：**彩数洞察**

### 1.2 产品定位

彩数洞察是一个面向中国彩票用户的彩票信息与数据分析网站，主要提供福利彩票、体育彩票相关的开奖数据、历史趋势分析、中奖信息整理、概率性号码生成和彩票相关新闻趣事。

产品重点聚焦福利彩票中的**双色球**，在后续版本中逐步扩展体育彩票中的超级大乐透，以及其他福彩、体彩玩法。

### 1.3 产品目标

1. 为用户提供及时、准确、可追溯的彩票开奖数据。
2. 围绕双色球建立完整的数据分析能力。
3. 提供基于规则和历史数据的娱乐性号码生成工具。
4. 自动聚合彩票相关新闻、中奖故事和政策公告。
5. 建立一个理性、合规、不提供售彩能力的彩票信息平台。

### 1.4 产品边界

本站只提供彩票信息整理、数据分析和娱乐性号码生成服务。

不提供：

- 在线购买彩票
- 代购彩票
- 合买
- 跟单
- 充值提现
- 付费预测
- 保证中奖类服务
- 赌博或非法彩票网站导流

## 2. 目标用户

### 2.1 核心用户

| 用户类型 | 核心需求 |
|---|---|
| 普通购彩用户 | 查看最新开奖、历史开奖、中奖信息 |
| 数据分析爱好者 | 分析号码走势、冷热号、遗漏、和值等 |
| 内容浏览用户 | 阅读中奖故事、彩票趣闻、政策信息 |
| 彩票内容站运营者 | 自动更新开奖和资讯内容 |
| 理性购彩用户 | 用数据辅助娱乐性选号 |

### 2.2 用户场景

#### 场景一：查看最新开奖

用户进入首页后，希望第一时间看到最新双色球开奖号码、开奖期号、开奖日期、奖池金额和一等奖中奖情况。

#### 场景二：分析历史走势

用户希望查看最近 30 期、50 期、100 期或全部历史数据中，红球、蓝球的出现频率、遗漏情况、和值走势、奇偶比例等。

#### 场景三：生成参考号码

用户并不期望系统真正预测中奖号码，而是希望系统基于某些规则生成几组参考号码，例如热号优先、冷号回补、随机均衡、混合权重等。

#### 场景四：阅读中奖故事

用户希望浏览最近的彩票大奖新闻、中奖地区、中奖站点、领奖故事和彩票相关趣闻。

## 5.5 数据分析

### 5.5.1 功能目标

基于历史开奖数据，为用户提供双色球号码、奖金、地区、站点等维度的数据分析。

### 5.5.2 号码频率分析

展示：

- 红球出现次数
- 蓝球出现次数
- 高频号码
- 低频号码
- 号码出现占比
- 最近出现期号
- 当前遗漏期数
- 最大遗漏期数
- 平均出现间隔

支持统计周期：

- 最近 30 期
- 最近 50 期
- 最近 100 期
- 最近 365 天
- 全历史

### 5.5.3 冷热号分析

定义：

- 热号：指定周期内出现频率明显高于平均水平的号码
- 温号：出现频率接近平均水平的号码
- 冷号：出现频率明显低于平均水平或遗漏期数较长的号码

展示：

- 热号榜
- 冷号榜
- 温号列表
- 最近变化趋势

### 5.5.4 遗漏分析

展示：

- 每个号码当前遗漏期数
- 每个号码最大遗漏期数
- 每个号码平均遗漏期数
- 当前遗漏排名
- 遗漏趋势图

### 5.5.5 区间分析

双色球红球区间划分：

- 一区：1–11
- 二区：12–22
- 三区：23–33

分析：

- 每期三区分布
- 常见区间组合
- 最近 N 期区间走势
- 极端区间组合次数

### 5.5.6 奇偶分析

展示：

- 当期奇偶比
- 最近 N 期奇偶比走势
- 历史最常见奇偶组合
- 极端奇偶组合出现次数

示例：

| 奇偶比 | 说明 |
|---|---|
| 3:3 | 奇数 3 个，偶数 3 个 |
| 4:2 | 奇数 4 个，偶数 2 个 |
| 2:4 | 奇数 2 个，偶数 4 个 |
| 5:1 | 奇数 5 个，偶数 1 个 |
| 1:5 | 奇数 1 个，偶数 5 个 |

### 5.5.7 大小号分析

定义：

- 小号：1–16
- 大号：17–33

展示：

- 当期大小比
- 最近 N 期大小比走势
- 历史常见大小组合
- 极端大小组合统计

### 5.5.8 和值分析

红球和值指 6 个红球号码之和。

展示：

- 当期和值
- 历史平均和值
- 最近 N 期和值走势
- 常见和值区间
- 最大和值
- 最小和值

### 5.5.9 连号分析

展示：

- 是否出现连号
- 连号个数
- 连号组合
- 最近 N 期连号出现频率
- 历史常见连号组合

### 5.5.10 重号分析

重号指本期与上一期重复出现的红球号码。

展示：

- 是否出现重号
- 重号数量
- 重号号码
- 蓝球是否重复
- 最近 N 期重号趋势

### 5.5.11 奖金分析

展示：

- 奖池金额走势
- 销售金额走势
- 一等奖注数走势
- 一等奖单注奖金走势
- 二等奖注数走势
- 二等奖单注奖金走势
- 历史最高奖池
- 历史最高单注奖金

### 5.5.12 地区中奖分析

展示：

- 各省一等奖中奖次数
- 各省累计中奖金额
- 城市中奖榜
- 地区中奖热力地图
- 近一年中奖地区变化

### 5.5.13 投注站点分析

展示：

- 站点编号
- 站点地址
- 所属省市区
- 历史中奖次数
- 累计中奖金额
- 最近中奖时间
- 关联中奖新闻

## 5.6 号码预测

### 5.6.1 功能目标

基于历史数据和规则模型，为用户生成娱乐性参考号码。

该功能不承诺预测真实中奖号码，不提供购彩建议。

### 5.6.2 页面提示

预测页必须显著展示：

> 以下号码仅基于历史数据和规则模型生成，不能预测真实开奖结果，不构成购彩建议。彩票开奖结果具有随机性，请理性看待。

### 5.6.3 预测模式

#### 随机均衡模式

规则：

- 红球从 1–33 中随机选择 6 个
- 蓝球从 1–16 中随机选择 1 个
- 红球不重复
- 红球升序排列
- 可加入奇偶比、大小比、和值等均衡约束

适合用户：

- 新用户
- 娱乐型用户

#### 热号优先模式

规则：

- 根据最近 N 期出现频率计算号码权重
- 高频号码被选中的概率更高
- 支持选择统计周期

可选周期：

- 最近 30 期
- 最近 50 期
- 最近 100 期
- 全历史

#### 冷号回补模式

规则：

- 根据当前遗漏期数选择号码
- 遗漏较长的号码权重更高
- 避免全部选择极端冷号

#### 混合权重模式

综合因素：

| 因素 | 默认权重 |
|---|---:|
| 最近 50 期出现频率 | 30% |
| 全历史出现频率 | 20% |
| 当前遗漏期数 | 20% |
| 奇偶平衡 | 10% |
| 大小平衡 | 10% |
| 和值区间 | 10% |

#### 自定义规则模式

用户可配置：

- 生成注数
- 必选红球
- 排除红球
- 必选蓝球
- 排除蓝球
- 红球奇偶比
- 红球大小比
- 红球和值范围
- 是否允许连号
- 是否允许重号
- 统计周期
- 热号数量
- 冷号数量
- 温号数量

### 5.6.4 预测结果展示

每组号码展示：

- 红球
- 蓝球
- 生成模式
- 模型评分
- 和值
- 奇偶比
- 大小比
- 区间分布
- 是否包含连号
- 是否包含上期重号
- 每个号码的历史出现次数
- 每个号码的当前遗漏期数
- 生成解释

### 5.6.5 预测历史

系统可保存预测记录，用于开奖后回看。

保存内容：

- 生成时间
- 目标期号
- 预测模式
- 规则参数
- 生成号码
- 开奖后命中情况

展示原则：

- 只用于透明记录
- 不用于夸大预测准确率
- 不做营销宣传

## 6. 合规与风控要求

### 6.1 全站合规原则

1. 不销售彩票。
2. 不代购彩票。
3. 不提供支付能力。
4. 不承诺中奖。
5. 不展示诱导性文案。
6. 不允许非法彩票网站广告。
7. 不面向未成年人推广。

### 6.2 禁止使用的营销词

包括但不限于：

- 必中
- 包中
- 稳赚
- 内部号
- 专家带单
- 无风险
- 高回报
- 投注入口
- 代买
- 返利

### 6.3 预测页风控

预测页必须展示：

> 本功能仅用于数据娱乐和规则演示，不代表真实预测结果，不构成任何购彩建议。

### 6.4 新闻内容风控

需要过滤：

- 赌博引流
- 非法彩票网站
- 诱导扫码投注
- 代购信息
- 虚假中奖信息
- 赌博诈骗内容

## 11. 风险与应对

### 11.1 数据源不稳定

风险：

- 官方页面结构变化
- 数据接口变化
- 抓取失败
- 数据延迟

应对：

- 多源采集
- 官方源优先
- 数据异常标记
- 后台人工审核
- 抓取失败告警

### 11.2 版权风险

风险：

- 新闻全文搬运可能产生版权问题。

应对：

- 只展示摘要
- 标注来源
- 跳转原文
- 支持删除和隐藏
- 避免大段复制原文

### 11.3 预测误导风险

风险：

- 用户误以为系统可以预测真实开奖结果。

应对：

- 明确免责声明
- 不使用夸大词汇
- 不提供付费预测
- 不提供购彩入口
- 预测结果解释为规则生成

### 11.4 合规风险

风险：

- 网站被误认为线上售彩平台。

应对：

- 全站声明不售彩
- 不接入支付
- 不提供交易功能
- 不出现投注按钮
- 不展示非法彩票网站广告
