# 智能体工作规则

## 1. 开始任务前

1. 读根目录 `AGENTS.md`。
2. 根据任务类型读取 `docs/specs` 或 `docs/rules`。
3. 用 `rg` 查找现有实现，不要凭记忆猜路径。

## 2. 修改代码时

- 核心逻辑先补测试。
- 不要把业务规则写进 UI 组件。
- 不要删除 Next.js 自动生成的 AGENTS 块。
- 不要把彩票销售相关能力加入项目。

## 3. 完成前

必须运行：

```bash
npm test
npm run build
```

如果只改文档，也至少检查：

```bash
find docs -type f | sort
```

## 4. 回答用户时

- 说明改了哪些文件。
- 说明验证命令和结果。
- 如果有未完成项，明确列出。
