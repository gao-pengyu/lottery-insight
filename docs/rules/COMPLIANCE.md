# 彩票合规规则

## 1. 禁止功能

禁止新增以下能力：

- 在线售彩
- 代购彩票
- 合买
- 跟单
- 支付
- 充值
- 提现
- 返佣
- 付费预测
- 投注入口
- 非法彩票网站导流

## 2. 禁止文案

禁止出现或用于营销：

- 必中
- 包中
- 稳赚
- 内部号
- 专家带单
- 无风险
- 高回报
- 预测准确率承诺

## 3. 预测免责声明

预测页面和预测结果必须表达：

> 号码仅基于历史数据和规则模型生成，不能预测真实开奖结果，不构成购彩建议。

## 4. 个人信息规则

不得采集或展示：

- 真实姓名
- 身份证号
- 手机号
- 住址
- 银行卡

只允许展示公开报道中的匿名化描述，例如“某地购彩者”。

## 5. 新闻内容规则

- 只展示摘要、来源、发布时间和链接。
- 不整篇搬运第三方文章。
- 发现赌博引流、扫码投注、代购内容时不得发布。
