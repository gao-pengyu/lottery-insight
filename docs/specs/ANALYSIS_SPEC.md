# 数据分析规格

## 1. 文件

实现文件：`src/lib/analysis.ts`

测试文件：`src/__tests__/analysis.test.ts`

## 2. 支持指标

| 指标 | 说明 |
|---|---|
| 号码频率 | 红球/蓝球在统计窗口内出现次数 |
| 当前遗漏 | 最新一期之前连续未出现期数 |
| 最大遗漏 | 历史连续未出现最大期数 |
| 平均间隔 | 两次出现之间的平均间隔 |
| 和值走势 | 每期 6 个红球之和 |
| 奇偶比 | 奇数个数:偶数个数 |
| 大小比 | 小号 1-16，大号 17-33 |
| 区间比 | 1-11、12-22、23-33 |
| 连号 | 排序后相邻号码差值为 1 |
| 重号 | 与上一期红球交集 |

## 3. 纯函数约束

`analysis.ts` 必须保持纯函数：

- 不读写文件。
- 不请求网络。
- 不依赖页面状态。
- 输入相同，输出必须相同。

## 4. 修改要求

修改分析逻辑时必须同步更新或新增测试。
