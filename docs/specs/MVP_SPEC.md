# 最小可用版本 实现规格

## 1. 范围

当前 最小可用版本 只要求完整支持双色球，不要求完整支持大乐透、福彩 3D、七乐彩、排列 3、排列 5、7 星彩。

## 2. 必须支持的用户路径

1. 用户打开首页，可以看到最新双色球开奖。
2. 用户进入历史开奖页，可以看到最近开奖列表。
3. 用户点击期号，可以查看单期开奖详情。
4. 用户进入数据分析页，可以看到频率、遗漏、和值和比例分析。
5. 用户进入号码生成页，可以生成娱乐性参考号码。
6. 用户进入新闻页，可以看到资讯摘要。
7. 运维进入后台页，可以查看采集任务和数据质量问题。
8. 运维可以手动刷新官方数据。

## 3. 验收标准

| 项 | 标准 |
|---|---|
| 本地启动 | `npm run dev` 后可打开 `http://localhost:3000` |
| 初始化 | `npm run setup` 能生成 `data/db.json` |
| 测试 | `npm test` 通过 |
| 构建 | `npm run build` 通过 |
| 刷新 | `POST /api/crawlers/refresh` 返回成功 JSON 数据文件 |
| 合规 | 页面无售彩、代购、支付、必中承诺 |

## 4. 暂不做

- 用户登录
- 收藏号码
- 评论社区
- 付费会员
- 在线购买彩票
- 大规模新闻抓取
- 全彩种深度分析
